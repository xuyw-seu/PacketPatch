# dataset/ — Dataset Documentation

This directory provides documentation for the datasets used to evaluate PacketPatch. The actual dataset files are NOT included in this repository due to size constraints; please download them from the provided links.

## Datasets Overview

PacketPatch is evaluated on three publicly available encrypted traffic datasets:

| Dataset | Classes | Train/Val/Test | Scenario | Year |
|---------|---------|----------------|----------|------|
| **ISCX-TOR** | 16 | 8:1:1 | Tor anonymous network traffic | 2017 |
| **ISCX-VPN** | 11 | 8:1:1 | VPN encrypted tunnel traffic | 2016 |
| **USTC** | 20 | 8:1:1 | Malware + benign encrypted traffic | 2017 |

---

## ISCX-TOR Dataset

**Scenario**: Traffic generated by accessing services through the Tor network.

**16 Traffic Categories**:

| Category | Samples | Category | Samples |
|----------|---------|----------|---------|
| Facebook | 20,066 | Imap | 21,000 |
| Vuze | 21,000 | Skype | 21,183 |

| Aim | 620 | POP | 21,000 |
| Multiplespeed | 21,000 | FTP | 21,000 |
| SSL | 21,000 | Youtube | 21,000 |

## USTC Dataset

**Scenario**: Network security focused — malware traffic vs. benign encrypted traffic.

**20 Traffic Categories** (10 malware + 10 benign):

| Type | Categories |
|------|------------|
| **Benign** | BitTorrent, Facetime, FTP, Gmail, MySQL, Outlook, Skype, SMB, Weibo, WorldOfWarcraft |
| **Malware** | Cridex, Geodo, Htbot, Miuref, Neris, Nsis-ay, Shifu, Tinba, Virut, Zeus |

**Source**: Wang et al., "Malware Traffic Classification using Convolutional Neural Network for Representation Learning", ICOIN 2017.

## Data Format (After Preprocessing)

The code expects data in preprocessed format:

### Expected File Structure

```
D:\dataset_packet\
├── {dataset_name}_dataset_split\
│   └── {task_name}\                      # e.g., application_classification
│       ├── train\
│       │   ├── x_bert.pickle              # Token sequences
│       │   └── y.npy                      # Labels
│       ├── val\
│       │   ├── x_bert.pickle
│       │   └── y.npy
│       └── test\
│           ├── x_bert.pickle
│           └── y.npy
```

### File Descriptions

| File | Format | Description |
|------|--------|-------------|
| `x_bert.pickle` | Python pickle | List of tokenized packet sequences (each packet = list of token IDs from BPE vocabulary) |
| `y.npy` | NumPy array | Integer labels (0 to num_classes-1) for each packet |

---

## Preprocessing Pipeline

The raw `.pcap` files must be preprocessed before use. The general pipeline is:

```
Raw PCAP → Extract packet bytes → BPE Tokenization → Sequence padding/truncation → pickle/npy
```

> **Important**: The preprocessing code is NOT included in this repository. We recommend using the data preprocessing utilities from the [ET-BERT](https://github.com/linwhitehat/ET-BERT) project, as PacketPatch is built on the same data representation.

### Recommended Steps

1. Download raw datasets (PCAP files) from their original sources
2. Use ET-BERT's preprocessing scripts to:
   - Extract byte sequences from packets
   - Perform BPE tokenization with `encryptd_vocab.txt`
   - Split into train/val/test (8:1:1)
   - Save as `x_bert.pickle` and `y.npy`
3. Organize files following the expected directory structure above
